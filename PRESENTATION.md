# Roteiro de Apresentação — Restaurante Landing

1. Introdução (30s)
   - Nome do projeto: Restaurante Sabor & Arte
   - Objetivo: apresentar uma Landing Page responsiva construída com React + Vite

2. Demonstração ao vivo (2-3 min)
   - Rodar `npm run dev` e abrir `http://localhost:5173`
   - Mostrar a seção Hero, o menu em cards e o rodapé
   - Redimensionar a janela para demonstrar responsividade

3. Estrutura do código (1-2 min)
   - Mostrar `src/App.jsx` (componentes Hero, Menu, Footer)
   - Mostrar `src/styles.css` e explicar as variáveis CSS e grid responsivo

4. Deploy (30s)
   - Explicar como publicar no GitHub Pages com `npm run deploy`

5. Próximos passos / melhorias (30s)
   - Adicionar imagens profissionais e galeria
   - Formulário de contato e integração com backend
   - Animações sutis e otimizações de SEO
