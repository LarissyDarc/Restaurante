## 📌 Sobre o Projeto

Landing Page responsiva para restaurante, desenvolvida com **React + Vite**, apresentando o restaurante, menu de destaque e chamada para reservas.

## 🚀 Funcionalidades

* Layout responsivo para mobile e desktop
* Seção Hero
* Menu de destaque
* Rodapé
* Chamada para reservas
* API Node.js para validação e registro temporário de reservas (`POST /api/reservas`)
* Publicação no GitHub Pages

## 🛠️ Tecnologias

* React
* Vite
* JavaScript
* CSS
* GitHub Pages

## ▶️ Como Executar

```bash
npm install
npm run dev
```

## 🧪 Testes do back-end

Execute os testes unitários da validação e da API de reservas:

```bash
npm test
```

`npm run dev` inicia a interface e a API local. As reservas são mantidas somente em memória enquanto o servidor está ativo. Consulte [TESTES_BACKEND.md](TESTES_BACKEND.md) para os cenários planejados, resultados e limitações.
